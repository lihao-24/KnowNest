# xuefeng-agent 知识库精选摘录

本文件不是上游 `knowledge_base.md` 的完整复制，而是为本项目人工筛选后的可用部分。原始知识库里包含大量学校榜单、专业红黑榜、就业趋势和 2025-2026 判断，这些内容缺少可追溯来源，不进入本项目参考资料。

## 可复用部分

### 咨询哲学

- 先收集硬信息，再给建议。
- 志愿咨询不能只问兴趣，要结合就业、地域、家庭资源和长期路径。
- 对普通家庭，建议优先关注专业对口性、就业稳定性、考公/考编/央国企机会和城市产业匹配。
- 对有行业资源的家庭，可以考虑资源承接，例如电力、铁路、医疗、教育等。

### 必问信息

1. 省份
2. 科类或选科
3. 分数
4. 位次
5. 批次线
6. 专业兴趣和明确排斥项
7. 城市偏好和不能接受的地域
8. 家庭资源、预算和就业期待
9. 未来诉求：就业、考研、考公、稳定、高薪、离家近等

### 信息采集顺序

```text
第一步：硬分 — 省份 + 分数 + 位次 + 选科
第二步：兴趣 — 想学什么大类？最讨厌什么？
第三步：地域 — 想去哪？不去哪？有没有特殊限制？
第四步：家庭 — 父母行业、家庭资源、预算和风险承受能力
第五步：诉求 — 就业第一？考公第一？深造第一？稳定第一？
```

信息不全时，助手应优先追问，不直接生成完整志愿方案。

### 位次法

- 位次比分数更稳定。
- 分数每年受试卷难度和批次线影响，位次更能体现考生在本省的相对位置。
- 高考出分后应查一分一段表，拿到全省位次，再参考近年同位次录取情况。
- 需要看趋势，不能只盯单年数据。

本项目实现时必须把位次法绑定到河南省官方一分一段表和近年投档/录取数据。

### 冲稳保表达

上游知识库提供了“冲、稳、保”分层表达方式，但具体阈值不能照搬。河南省项目应基于河南当年志愿规则、招生计划和近年位次波动重新定义。

输出时可以沿用结构：

```text
冲：录取可能较低，但值得尝试；必须说明调剂、专业和滑档风险。
稳：与考生位次较匹配；重点说明专业组和计划变化。
保：以确保录取为目标；需要检查是否能接受学校、城市和专业。
```

### 学校、专业、城市取舍

可借鉴的判断框架：

- 高分段更重视学校平台和长期机会。
- 中分段更重视专业对口和就业路径。
- 分数较低时，城市和实习机会、行业特色院校可能更重要。
- 医学、师范、农学等地域属性强的方向，要把未来就业地纳入判断。

以上只能作为解释框架，不能替代河南省录取数据。

### 表达风格

可借鉴：

- 直白指出风险。
- 先讲结论，再讲原因。
- 多用家长和考生能听懂的话。
- 对“听起来热门但实际门槛高/就业不稳”的方向要主动提醒。

需要避免：

- 羞辱式、歧视性、绝对化表达。
- 把短视频观点包装成事实。
- 用“肯定能上”“一定不能报”等无边界判断。

### 数据可信度分级

上游知识库提出了有价值的数据分级思路。本项目采用更严格版本，详见 `../../data-trust-model.md`。

简化原则：

- T1：河南省官方考试招生数据。
- T2：高校官方招生数据。
- T3：权威公共平台和就业质量报告。
- T4：经验规律和咨询方法论。
- T5：AI 推测、网络观点、未核验榜单。

T4/T5 不能用于录取概率计算。

## 明确不保留的上游内容

以下内容不进入本项目参考资料：

- 具体专业推荐/不推荐榜单。
- “钱途最好专业”等无来源榜单。
- 城市产业速查表。
- 学校联盟、行业名校、华为校招目标院校、用人单位认可排名等榜单。
- 2025-2026 就业趋势和 AI 替代风险的具体数字。
- 考研、大学四年安排、专科规划、高中规划等非第一阶段核心内容。

如后续需要相关能力，必须重新基于官方或可追溯来源建模。
