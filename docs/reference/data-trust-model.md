# 数据可信度模型

本项目必须把“可追溯数据”和“AI 风格化表达”分开。AI 可以帮助解释和对比，但不能凭模型常识生成录取结论。

## 可信等级

| 等级 | 类型 | 示例 | 使用方式 |
| --- | --- | --- | --- |
| T1 | 河南省官方考试招生数据 | 河南省教育考试院一分一段表、批次线、投档线、志愿填报规则 | 可用于录取风险、位次对比和规则判断 |
| T2 | 高校官方数据 | 招生章程、招生计划、招生网录取分数、选科要求 | 可用于专业限制、计划变化和院校核验 |
| T3 | 官方或权威公共平台汇总 | 阳光高考、高校就业质量报告、教育部公开信息 | 可用于辅助说明，重要结论仍需回查原始来源 |
| T4 | 经验规律和咨询方法论 | 位次法、冲稳保经验、学校专业城市取舍 | 可用于解释和建议，不可单独作为录取依据 |
| T5 | AI 推测或未核验公开说法 | 模型常识、网络文章、短视频观点、未标来源榜单 | 只能用于启发式讨论，输出时必须提示未核验 |

## 输出原则

- 涉及分数、位次、招生计划、专业组、录取概率时，必须优先使用 T1/T2。
- T3 可作为辅助材料，但关键字段要尽量追溯到 T1/T2。
- T4 只能解释方法，不能替代真实数据。
- T5 不得作为最终推荐依据。
- 所有推荐都应说明数据年份、来源和适用范围。

## 对 `xuefeng-agent` 知识库的使用边界

`ziqihe10-droid/xuefeng-agent` 的知识库适合借鉴：

- 咨询追问流程
- 就业倒推视角
- 家庭资源和地域约束
- 风险提示表达
- 冲稳保输出结构

不适合直接用于：

- 河南省录取概率计算
- 学校或专业组具体推荐
- 最新招生政策判断
- 当年招生计划变化判断
- 可核验事实引用

## 数据入库建议

后续每条招生相关数据至少保留：

- `source_name`
- `source_url`
- `source_published_at`
- `data_year`
- `province`
- `batch`
- `subject_type` 或 `elective_requirements`
- `school_name`
- `major_name` 或 `major_group`
- `plan_count`
- `min_score`
- `min_rank`
- `trust_level`
- `imported_at`

字段会在技术栈确定后迁移到正式数据模型。
